# Zona Nadadores CN Salou

App de los nadadores del Club Natació Salou: marcas, mínimas, calendario, normativas, entrenamientos, valoraciones y salowis.

Abrir: https://cnsalou.github.io/zona-nadadores/

## Cómo instalarla en el móvil
- **iPhone (Safari):** abre el enlace, pulsa **Compartir** y después **Añadir a pantalla de inicio**.
- **Android (Chrome):** abre el enlace y pulsa **Instalar** (o menú ⋮ → **Instalar aplicación**).

Los datos no están en este repositorio: los sirve un Google Apps Script del club (ver `config.js`).
